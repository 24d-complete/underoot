# Underoot

**Underoot** is a privacy-focused, offline-capable alternative to Overleaf, built on top of [VSCodium](https://github.com/VSCodium/vscodium). 

It aims to provide a reliable, "batteries-included" LaTeX Integrated Development Environment (IDE) that eliminates the complexity of setting up local LaTeX environments while removing Microsoft telemetry and data collection.

## Key Goals

1.  **Privacy & Freedom**: Based on VSCodium to ensure a telemetry-free experience.
2.  **Zero Configuration**: Comes with a bundled LaTeX distribution (Tex Live) and essential extensions (LaTeX Workshop), so it works out of the box.
3.  **Focused UI**: A minimalist interface tailored for academic writing, hiding unnecessary software development tools.
4.  **Portability**: Designed to run entirely from a portable folder or USB drive.

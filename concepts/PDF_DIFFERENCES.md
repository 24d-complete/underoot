# PDF Rendering Differences Analysis: Underoot vs. Overleaf

## Executive Summary
The visual differences between the PDFs generated by Underoot and Overleaf—specifically the fonts and page count—are caused by **missing font packages** in the Underoot local LaTeX environment. 

While Overleaf has the full TeX Live suite installed, the local Underoot environment is missing strict dependencies for the `acmart` class (`libertine`, `inconsolata`, `newtx`). The `acmart` document class detects these missing files but, instead of halting compilation with an error, it **gracefully degrades** to default fonts (Computer Modern). 

Because the compilation succeeds (exit code 0) without a "File not found" critical error, the local auto-installer (`texliveonfly`) is never triggered to fetch the missing packages.

## detailed Findings

### 1. Font Discrepancy
*   **Overleaf Render**: Uses **Linux Libertine** (serif) for body text, **Inconsolata** for monospace, and **NewTX** for math. These are the standard fonts prescribed by the ACM template.
*   **Underoot Render**: Uses **Computer Modern** (standard LaTeX default). This font is wider and has different metrics, which causes text to flow differently, changing line breaks and ultimately increasing the page count (e.g., from 30 pages on Overleaf to 32 pages locally).

### 2. Evidence from Logs
The log file `logs/underoot/latex_compiler.txt` contains explicit warnings confirming this:

```text
Class acmart Warning: You do not have the libertine package installed. Please upgrade your TeX on input line 854.
Class acmart Warning: You do not have the inconsolata (zi4.sty) package installed. Please upgrade your TeX on input line 857.
Class acmart Warning: You do not have the newtxmath package installed. Please upgrade your TeX on input line 860.
```

In contrast, the Overleaf log (`logs/overleaf/browser_based_logs.txt`) shows these files being successfully loaded:
```text
Package: libertine 2024/04/23 (Bob Tennent) Supports Libertine and Biolinum fonts...
Package: zi4 2019/05/17 v1.12 ...
Package: newtxmath 2024/09/22 v1.754 ...
```

### 3. Why Auto-Install Failed
The local build system uses usage-based installation (`texliveonfly` or similar wrapper). This tool works by:
1.  Running `pdflatex`.
2.  Checking if it failed with a `! LaTeX Error: File 'xxx.sty' not found.`
3.  Installing `xxx` and retrying.

However, the `acmart.cls` file checks for these fonts using `\IfFileExists`. If the check fails, it issues a **Warning** (not an Error) and continues using fallback fonts. 
**Result:** The build looks "successful" to the automation tools, so they never attempt to install the missing fonts.

## Recommendations for Fix

To match the Overleaf output, you must ensure these packages are installed. Since the automatic detection is being bypassed, you have two options:

### Option A: Manual Installation (Recommended)
Manually install the required font packages into your local TeX Live distribution.
*   `libertine`
*   `inconsolata`
*   `newtx`

### Option B: Force Automatic Installation
Create a temporary dummy file (e.g., `install_fonts.tex`) that explicitly requires these packages *without* the graceful check, and compile it once. This will trigger the "File not found" error and force the auto-installer to work.

**install_fonts.tex:**
```latex
\documentclass{article}
\usepackage{libertine}
\usepackage{zi4}
\usepackage{newtxmath}
\begin{document}
Hello
\end{document}
```
Compiling this file locally should force the download of the missing fonts. Once installed, your main project will use them automatically.

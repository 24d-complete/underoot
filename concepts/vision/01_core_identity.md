# Core Identity & Vision

## Product Name
**Underoot**

## Tagline
**Full Fledged IDE for LaTeX for Writers**

## Visual Identity
*   **Logo Strategy**: Temporarily retain VSCodium branding/logo for the initial phases (Stage 0.x).
*   **Future Goal**: Develop a custom logo representing "Underoot" (roots, earth, foundational).

## Core Philosophy
*   **Privacy First**: No telemetry (inherited from VSCodium).
*   **Writer-Centric**: A "Full Fledged IDE", but specialized for LaTeX writers, not generic code.
*   **Offline Capable**: "Batteries included" approach to dependencies.
